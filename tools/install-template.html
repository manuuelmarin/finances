Actualizar el proyecto conectado

  1. Conserva el mismo proyecto, URL de implementación y propiedades privadas del script. Mantén el libro y el entorno ya configurados.
  2. Sustituye el contenido del archivo inicial Code.gs (puede llamarse Código.gs) por el backend completo generado de esta página. Los módulos antiguos pueden permanecer: este backend funciona de forma aislada. Sustituye Bridge.html. En una instalación nueva, añade también appsscript.json; el manifiesto no cambia desde 3.10.2. No copies la fachada corta del directorio de fuentes.
  3. Guarda todos los archivos. En Apps Script ejecuta prepareApplication y luego checkApplication para preparar y comprobar el backend. Si falla un envío, ejecuta checkSending: comprueba su preparación sin registrar movimientos. Debe indicar runtimeDelivery: single-file y prepared: true.
  4. Cuando las comprobaciones estén listas, abre Implementar → Gestionar implementaciones, pulsa el lápiz de la implementación web existente y elige Nueva versión. Conserva esa implementación y su URL; ejecuta como Yo y limita el acceso a Solo yo. No cambies el libro ni el entorno seleccionado; confirma que las propiedades privadas se conservan.
  5. Tras implementar, recarga Finanzas y comprueba que la conexión informa la API y el bridge vigentes. No crees otra implementación: la app debe seguir usando la misma URL privada.
  6. Para guardar cotizaciones verificadas, ejecuta enableDailyPrices una vez tras esta actualización para renovar su activador y después updatePrices. Ejecuta checkApplication para revisar el estado. Para detener la rutina diaria, ejecuta disableDailyPrices.

Guarda todo antes de ejecutar las funciones. La instalación conserva el entorno ya configurado; no cambies las propiedades del script.

COTIZACIONES

Acumular precios cada día

La rutina diaria se activa solo al ejecutar enableDailyPrices desde el proyecto ya configurado. Revisa checkApplication para confirmar su estado. La instalación del código no activa la rutina automáticamente.

Para consultar y guardar precios ahora, ejecuta updatePrices. Para pausar las consultas automáticas, ejecuta disableDailyPrices.
