## Verification boundaries

Validation passed: build, formatting, lint, 264 unit/backend tests and 119 desktop/mobile browser tests. Spending and goal layouts were also inspected from responsive screenshots.

Checks cover exact cross-month dates, selected-category totals, refund signs, unknown values, frequency counts, transaction drilldowns, goal assignments and opposite account discrepancies. The browser purchase checks persist canonical operation/movement inputs and replay the same request without duplication. Their Sheet fixture preserves native formulas but does not emulate Google Sheets recalculation; independent cash projections are checked separately.

No Apps Script source, workbook binding, private financial record, deployment URL or daily-price trigger is changed by this correction. From an intact 3.9.3/3.9.4 Google installation, the six-file update documented in RELEASE-CHECKLIST.md is still required for 3.10.0 interval support. This frontend correction adds no further Google files.

After the correction is merged and published, accept the app update, then verify the existing private test deployment with checkApplication and Comprobar sistema. A successful repository build is not proof of the owner's installed Google version, physical phone or latest fund-price publication. Production activation remains a separate action.
